# Определения

<hr />

- 🕊️ **Тайл**: Сетка пикселей `8x8` _в оттенках серого_, представляющая **паттерн**. Тайлы хранятся в 🕊️📖 таблицах паттернов.
  <div class="embed-image"><img alt="Тайл" src="assets/graphics/tile_grayscale.png" style="width: 30%" /></div>
  
- 🕊️📖 **Таблица паттернов**: Список 🕊️ тайлов, **хранящийся** в 👾 CHR-ROM или 👾 CHR-RAM.
<div class="embed-image"><img alt="Таблица паттернов" src="assets/graphics/tiles_grayscale.png" style="width: 30%" /></div>

<hr />

- 🏞️ **Фон**: **Статичное изображение** за спрайтами, хранящееся в 🏞️📖 таблице имён.

- 🏞️📖 **Таблица имён**: Карта **индексов тайлов** для фона, хранящаяся в 🐏 VRAM.

- 🖍️📖 **Таблицы атрибутов**: Карта **индексов палитр** для фона, хранящаяся в конце каждой 🏞️📖 таблицы имён.
<div class="embed-image"><img alt="Фон" src="assets/graphics/background.png" style="width: 30%" /></div>

<hr />

- 🛸 **Спрайт**: **Игровой объект** поверх фона (или за ним!), который можно перемещать или отражать, хранящийся в 🛸📖 OAM. Может использовать один 🕊️ тайл (спрайт `8x8`) или два (спрайт `8x16`).

- 🛸📖 **OAM**: _(Object Attribute Memory — память атрибутов объектов)_ Список спрайтов, хранящийся в 🐏 OAM RAM.
<div class="embed-image"><img alt="Спрайты" src="assets/graphics/sprites.png" style="width: 30%" /></div>

<hr />

- 🎨 **Палитра**: Список из `4` цветов, хранящийся в 🐏 RAM палитр, где каждый цвет — указатель на основную палитру. Всего `8` палитр: `4` для фона и `4` для спрайтов.

- 👑🎨 **Основная палитра**: Список из 64 **цветов**, заданных в коде. Палитры ссылаются на эти цвета индексами от `$00` до `$3F`.
<div class="embed-image"><img alt="Основная палитра" src="assets/graphics/colors.png" style="width: 50%" /></div>

<hr />

#### Области памяти PPU

- 🐏 VRAM (`2` КиБ)
- 🐏 RAM палитр (`32` байта)
- 🐏 OAM RAM (`256` байт)
