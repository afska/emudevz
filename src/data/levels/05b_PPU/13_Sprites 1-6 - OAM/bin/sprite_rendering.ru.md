# Отрисовка спрайтов

- 🛸📖 Таблица OAM — это массив из `64` 🛸 записей OAM.
- Каждая 🛸 запись OAM представляет один спрайт и занимает `4` байта.
- 🐏 OAM RAM содержит полную таблицу OAM (`256` байт).
  - (доступ к ней возможен только через 🏠 OAMAddr / 📝 OAMData / ⚡ OAMDMA)
- Если бит `5` регистра 🎛️ PPUCtrl (_высота спрайтов_) установлен, спрайты рисуются в режиме `8x16` вместо `8x8`.

## Формат записи OAM

- Байт `0`: Координата **Y** спрайта (минус `1`).
- Байт `1`: _Индекс 🕊️ тайла_ спрайта.
  - В режиме `8x8`:
    - Этот байт и есть _индекс тайла_.
    - Таблица паттернов определяется битом `3` регистра 🎛️ PPUCtrl (_выбор таблицы паттернов спрайтов_).
  - В режиме `8x16`:
    - _Индекс тайла_ для _верхнего тайла_ — этот байт со сброшенным первым битом (`byte1 & 0b11111110`).
    - _Индекс тайла_ для _нижнего тайла_ — _индекс верхнего тайла_ плюс `1`.
    - Таблица паттернов определяется первым битом (`byte1 & 0b00000001`).
- Байт `2`: Атрибуты спрайта.
  - Биты `0-1`: Идентификатор палитры.
  - Бит `5`: Приоритет (`0`: перед фоном, `1`: за фоном).
  - Бит `6`: Отражение по горизонтали.
  - Бит `7`: Отражение по вертикали.
- Байт `3`: Координата **X** спрайта.
