# Карта памяти PPU

| Диапазон адресов | Размер | Устройство |
| ------------- | ------- | ------------------------------------- |
| `$0000-$1FFF` | `$2000` | 🕊️ Таблицы паттернов 0 и 1 (маппер) |
| `$2000-$2FFF` | `$1000` | 🏞️ Таблицы имён от 0 до 3 (VRAM + зеркало) |
| `$3000-$3EFF` | `$0F00` | 🚽 Зеркала `$2000-$2EFF` |
| `$3F00-$3F1F` | `$0020` | 🎨 RAM палитр |
| `$3F20-$3FFF` | `$00E0` | 🚽 Зеркала `$3F00-$3F1F` |

#### Области памяти PPU

- 🐏 VRAM (`2` КиБ)
- 🐏 RAM палитр (`32` байта)
- 🐏 OAM RAM (`256` байт)
