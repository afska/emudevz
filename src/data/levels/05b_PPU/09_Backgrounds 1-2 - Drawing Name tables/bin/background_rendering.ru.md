# Отрисовка фона

- 🏞️📖 Таблица имён — это матрица `32x30` _индексов 🕊️ тайлов_.
- Разрешение экрана — `256x240`, а размер каждого 🕊️ тайла — `8x8` пикселей, поэтому эти `32x30` тайлов покрывают весь экран ✨.
- Каждый _индекс 🕊️ тайла_ занимает `1` байт, а в конце таблицы имён есть `64` байта 🖍️ _метаданных цвета_.
- Значит, каждая таблица имён занимает `1024` байта (`32*30*1 + 64`).
- 🐏 VRAM содержит `2` 🏞️📖 таблицы имён.
  - (они доступны по адресам PPU `$2000-$27FF`)

#### Отрисовка

##### ⬛️⬜️ Оттенки серого

- Найди расположение 🏞️📖 таблицы имён:
  - Первые `2` бита 🎛️ PPUCtrl содержат `nameTableId`.
  - Таблица находится по адресу PPU `0x2000 + nameTableId * 1024`.
- Определи, какую 🏞️📖 таблицу паттернов использовать (`0` или `1`):
  - Это указано в бите `4` регистра 🎛️ PPUCtrl.
- Каждый из следующих `960` байт — _индекс 🕊️ тайла_ (`0-255`).
  - Пока игнорируй 🖍️ _метаданные цвета_.
- На такте `0` каждой видимой строки (`0-239`) рисуй ряд пикселей (из `32` тайлов).
  - Используй фиксированную 🎨 палитру:
    - `[0xff000000, 0xff555555, 0xffaaaaaa, 0xffffffff]`.

##### 🎨🌈 Добавление цвета

###### **Получение идентификаторов палитр**

- Каждый раздел `«метаданных цвета»` — это 🖍️📖 таблица атрибутов, определяющая, какую 🎨 палитру использовать для каждого тайла.
- 🎨 Палитры содержат `4` цвета и назначаются `блокам` из `2x2` тайлов.

<div class="embed-image"><img alt="Блоки палитр" src="assets/graphics/palette-blocks.gif" style="width: 75%" /></div>

- Красная сетка показывает `блоки` палитр. Все тайлы в каждом блоке `2x2` используют одну палитру.
- Чтобы закодировать эти данные, экран сначала делят на `метаблоки` из `4x4` тайлов.

<div class="embed-image"><img alt="Метаблоки палитр" src="assets/graphics/palette-metablocks.gif" style="width: 75%" /></div>

- Зелёная сетка показывает `метаблоки`. Их `64`, по `1` байту на каждый `метаблок`.
- Каждый байт содержит:
  - Биты `0,1`: 🎨 _идентификатор палитры_ `блока 0` (слева сверху).
  - Биты `2,3`: 🎨 _идентификатор палитры_ `блока 1` (справа сверху).
  - Биты `4,5`: 🎨 _идентификатор палитры_ `блока 2` (слева снизу).
  - Биты `6,7`: 🎨 _идентификатор палитры_ `блока 3` (справа снизу).

###### **Чтение данных палитры**

- 🎨 Палитра — это массив из `4` 🖍️ _индексов цвета_ (`0-63`), ссылающихся на заданную в коде 👑🎨 основную палитру.
- Каждый 🖍️ _индекс цвета_ занимает `1` байт, поэтому каждая 🎨 палитра занимает `4` байта.
- 🐏 RAM палитр содержит `4` палитры для фона и `4` палитры для спрайтов.
  - (палитры фона доступны по адресам PPU `$3F00-$3F0F`)
