# Отрисовка тайлов

- 🕊️📖 Таблица паттернов — это список из `256` последовательных 🕊️ тайлов.
- Каждый 🕊️ тайл занимает `16` байт...
- ...так что каждая таблица паттернов занимает `4096` байт.
- 👾 CHR-ROM внутри 💾 картриджа содержит `2` 🕊️📖 таблицы паттернов.
  - (они доступны по адресам PPU `$0000-$1FFF`)

#### Отрисовка

- 🕊️ Тайл — это сетка пикселей `8x8` _в оттенках серого_.
- Значение пикселя может быть `0`, `1`, `2` или `3` в зависимости от цвета.
  - (в двоичном виде: `00`, `01`, `10` или `11`)

Для кодирования пикселей `16` байт данных тайла делятся на **две** **битовые плоскости** по `8 байт` (<strong style="color: #7723ec">младшую плоскость</strong> и <strong style="color: #4eeebf">старшую плоскость</strong>).

Вот пример того, как закодирован тайл для **½** (одной второй):

```
$41 $C2 $44 $48 $10 $20 $40 $80 $01 $02 $04 $08 $16 $21 $42 $87
```

<div class="embed-image"><img alt="Закодированный тайл" src="assets/graphics/one_half_fraction2.png" style="width: 75%" /></div>

Каждый бит первой плоскости управляет <strong style="color: #7723ec">битом 0</strong> цвета пикселя, а соответствующий бит второй плоскости — <strong style="color: #4eeebf">битом 1</strong>.
