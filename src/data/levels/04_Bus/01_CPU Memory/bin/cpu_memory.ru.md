# Карта памяти CPU

| Диапазон адресов | Размер | Устройство |
| --------------- | ------ | ---------- |
| `$0000-$07FF` | `$0800` | 🐏 WRAM (`2` КиБ) |
| `$0800-$1FFF` | `$1800` | 🚽 Зеркала `$0000-$07FF` |
| `$2000-$2007` | `$0008` | 🖥️ Регистры PPU |
| `$2008-$3FFF` | `$1FF8` | 🚽 Зеркала `$2000-$2007` |
| `$4000-$4013` | `$0014` | 🔊 Регистры APU |
| `$4014-$4014` | `$0001` | 🖥️ Регистр OAMDMA в PPU |
| `$4015-$4015` | `$0001` | 🔊 Регистры APUStatus / APUControl |
| `$4016-$4016` | `$0001` | 🎮 Порт контроллера 1 |
| `$4017-$4017` | `$0001` | 🎮 Порт контроллера 2 / 🔊 APUFrameCounter |
| `$4018-$401F` | `$0008` | 🧸 Не используется |
| `$4020-$FFFF` | `$BFE0` | 💾 Область картриджа (PRG-ROM, маппер и так далее) |

#### Области памяти CPU

- 🐏 WRAM (`2` КиБ)
