# Контроллер

NEEES поддерживает `2` контроллера, подключённых к адресам CPU `$4016` (игрок `1`) и `$4017` (игрок `2`).

## 🎮 Использование

Чтение адреса контроллера возвращает `1`, если кнопка нажата, и `0`, если нет. При каждом чтении опрашиваемая кнопка меняется в определённом порядке. Поэтому для получения состояния всех кнопок игре нужно выполнить `8` чтений.

Кнопки опрашиваются в таком порядке:

`A` -> `B` -> `Select` -> `Start` -> `Up` -> `Down` -> `Left` -> `Right`

После чтения состояния кнопки `Right` последующие чтения возвращают `1`, пока игра не сбросит последовательность, записав `1`, а затем `0` по адресу `$4016` (см. ниже).

## 🔄 Режим строба

При записи по адресу `$4016` (адрес контроллера игрока `1`) **младший бит** записываемого значения задаёт `режим строба`:

- когда бит строба `включён`, чтение всегда возвращает состояние кнопки `A`
- когда бит строба `выключен`, чтение продвигается по описанной выше последовательности

Включение бита строба **сбрасывает** последовательность к кнопке `A` **на обоих контроллерах**.

Запись по адресу `$4017` не влияет на контроллеры: она управляет регистром APU под названием 🧮  APUFrameCounter.
