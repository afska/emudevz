# Формат iNEEES

Файл iNEEES состоит из следующих разделов в указанном порядке:

<table style="margin-bottom: 16px; text-align: center;">
  <tr>
    <td>🗣️</td>
    <td style="width: 50px">🧸</td>
    <td style="width: 200px">🤖</td>
		<td style="width: 150px">👾</td>
  </tr>
</table>

- 🗣️ Заголовок (`16` байт)
- 🧸 Заполнитель, если есть (`0` или `512` байт)
- 🤖 Данные PRG-ROM (`16384` \* `x` байт)
  - `x` = байт `4` из заголовка
- 👾 Данные CHR-ROM (`8192` \* `y` байт)
  - `y` = байт `5` из заголовка

## 🗣️ Заголовок

Формат заголовка:

<div class="embed-image" style="margin-bottom: 16px"><img alt="Заголовок" src="assets/header.png" style="width: 75%" /></div>

- `0-3`: Константа `$4E $45 $53 $1A`
- `4`: Размер 🤖 PRG-ROM в блоках по `16` КиБ
- `5`: Размер 👾 CHR-ROM в блоках по `8` КиБ (значение `0` означает, что плата использует `8` КиБ 👾 CHR-RAM)
- `6`: Флаги 6 — 🗜️ маппер (младший ниббл), 🚽 зеркалирование, 🔋 сохранения игры (PRG-RAM), 🧸 заполнитель
- `7`: Флаги 7 — 🗜️ маппер (старший ниббл), 🧸 заполнитель
- `8-15`: 🧸 Неиспользуемый заполнитель

🗜️ Платы картриджей объединяются в классы, которые называются **мапперами**, по сходству оборудования и поведения. Каждому мапперу присвоен 8-битный номер.

🚽 Каждый картридж также задаёт **тип зеркалирования**, который напрямую влияет на расположение экранов и обработку прокрутки в игре.

Пока достаточно знать:

- 🗜️ ID маппера — любое число от `0` до `255`.
- 🚽 Тип зеркалирования — один из вариантов: `HORIZONTAL`, `VERTICAL`, `FOUR_SCREEN`.

### Флаги 6

```
76543210
||||||||
|||||||+- Зеркалирование: 0: HORIZONTAL (для вертикальной прокрутки)
|||||||                  1: VERTICAL (для горизонтальной прокрутки)
||||||+-- 1: Картридж содержит PRG-RAM (для сохранений)
|||||+--- 1: Файл содержит 512 байт заполнителя перед данными PRG-ROM
||||+---- 1: Игнорировать бит 0 и использовать зеркалирование FOUR_SCREEN
++++----- Младший ниббл номера маппера
```

### Флаги 7

```
76543210
||||||||
||||||||
||||||||
||||||||
||||||||
||||++++- Неиспользуемый заполнитель
++++----- Старший ниббл номера маппера
```
