# Создание шума

- У 💥 шумового канала есть 15-битный **сдвиговый регистр**, который периодически обновляется тактовыми событиями.
- При **включении питания** в сдвиговый регистр загружается значение `1`.
- Бит `7` регистра 🌪️ NoiseForm — это **флаг режима**, который влияет на характер шума.
- Биты `0-3` регистра 🌪️ NoiseForm задают индекс в фиксированной таблице периодов шума:

```javascript
[2, 4, 8, 16, 32, 48, 64, 80, 101, 127, 190, 254, 381, 508, 1017, 2034]
```

- Например, если **индекс периода** равен `3`, **период шума** равен `16`. Значит, сдвиговый регистр обновляется раз в `16` циклов APU (вызовов `step()`).

- При тактовом событии 15-битный сдвиговый регистр обновляется в таком порядке:

  - вычисляется бит обратной связи `feedback`:
    - если флаг режима установлен => `bit 0 ^ bit 6`
    - если флаг режима сброшен => `bit 0 ^ bit 1`
  - сдвиговый регистр **сдвигается вправо** на один бит (`>> 1`)
  - бит `14`, самый левый, заменяется вычисленным битом `feedback`

- Выходной отсчёт канала равен **громкости огибающей** или `0`, если выполняется хотя бы одно условие:
  - бит `0` сдвигового регистра установлен
  - счётчик длины равен `0`
