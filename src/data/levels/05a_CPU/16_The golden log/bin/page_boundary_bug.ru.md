# Баг на границе страницы

В **косвенном** режиме адресации есть баг.

Если адрес находится на границе страницы `($aaFF)`, младший байт читается из
`$aaFF`, как и ожидается, но старший байт берётся из `$aa00` (вместо `$ab00`).

Поэтому вместо простого вызова `read16(address)` реализация **косвенного** режима должна выглядеть так:

```javascript
buildU16(
  read(
    lowByteOf(address) === 0xff
      ? buildU16(highByteOf(address), 0x00)
      : address + 1
  ),
  read(address)
);
```
