# Режимы адресации

#### Простые

| Название | Пример | Размер входа | Вход | Выход (псевдокод) |
| -------- | ------ | ------------ | ---- | ----------------- |
| Неявный | `INX` | `0` | 🚫 | 🚫 |
| Непосредственный | `LDA #$08` | `1` | 🔢 _конечное_ **значение** | 🔢 |
| Абсолютный | `LDA $C002` | `2` | 🐏 _полный_ **адрес** | 🔢/🐏 |
| Нулевая страница | `LDA $15` | `1` | 🐏 _частичный_ **адрес** | 🔢/🐏 |
| Относительный | `BNE @label` | `1` | 🐏 _относительный_ **адрес** | 🐏 **(\*)**<br/>`toU16([PC] + toS8(address))` |
| Косвенный | `JMP ($4080)` | `2` | 🐏 _косвенный_ **адрес** | 🐏<br/>`read16(address)` |

#### Индексированные

| Название | Пример | Размер входа | Вход | Выход (псевдокод) |
| -------- | ------ | ------------ | ---- | ----------------- |
| Нулевая страница,X | `STA $60,X` | `1` | 🐏 _частичный_ **адрес** | 🔢/🐏<br/>`toU8(address+[X])` |
| Нулевая страница,Y | `STA $60,Y` | `1` | 🐏 _частичный_ **адрес** | 🔢/🐏<br/>`toU8(address+[Y])` |
| Абсолютный,X | `STA $4050,X` | `2` | 🐏 _полный_ **адрес** | 🔢/🐏 **(\*)**<br/>`toU16(address+[X])` |
| Абсолютный,Y | `STA $4050,Y` | `2` | 🐏 _полный_ **адрес** | 🔢/🐏 **(\*)**<br/>`toU16(address+[Y])` |
| Индексированный косвенный | `STA ($01,X)` | `1` | 🐏 _частичный_ **адрес** | 🔢/🐏<br/><br/>`const start = toU8(address+[X]);`<br/>`const end = toU8(start+1);`<br/><br/>`buildU16(read(end), read(start))` |
| Косвенный индексированный | `LDA ($03),Y` | `1` | 🐏 _частичный_ **адрес** | 🔢/🐏 **(\*)**<br/><br/>`const start = address;`<br/>`const end = toU8(start+1);`<br/>`const baseAddress = buildU16(read(end), read(start));`<br/><br/>`toU16(baseAddress+[Y])` |

<hr>

**(\*)** В этих режимах адресации _выход_ определяется как сумма _базового адреса_ и смещения. При пересечении границы страницы добавляется `1` такт (`cpu.extraCycles++`). Это происходит, когда старшие байты _базового адреса_ и _выхода_ различаются.

⚠️ Не у всех кодов операций пересечение страницы требует дополнительного такта, поэтому режимы адресации получают булево значение `hasPageCrossPenalty`. Оно указывает, нужно ли добавлять такты при пересечении границы страницы.
