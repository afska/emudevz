# Инструкции

#### Обозначения

- 🚫: Инструкция не принимает _аргументы_ (`"no"`).
- 🐏: Инструкция принимает адрес памяти (`"address"`) как _аргумент_.
- 🔢: Инструкция принимает значение (`"value"`) как _аргумент_.

#### 🧮 Арифметика

| Код | Название | Арг. | Описание |
| --- | -------- | ---- | -------- |
| `ADC` | Сложение с переносом | 🔢 | Прибавляет `value` к `[A]` вместе с флагом переноса (`[A]` = `[A]` + `value` + `C`), также обновляя флаги `Z` и `N`.<br><br>Флаги `C` и `V` устанавливаются при переполнении без знака и со знаком соответственно.<br><br>Переполнение без знака происходит, когда результат >= `256` (используй `byte.overflows(...)`).<br>Переполнение со знаком происходит, когда `Положительное + Положительное = Отрицательное` или `Отрицательное + Отрицательное = Положительное`. |
| `ASL` | Арифметический сдвиг влево | 🐏 | Сдвигает все биты значения по адресу `address` на одну позицию влево. Бит `7` помещается во флаг `C`, а бит `0` устанавливается в `0`.<br><br><div class="embed-image"><img alt="ASL" src="assets/bitshifts/ASL.gif" width="186" height="115" /></div><br>Флаги `Z` и `N` обновляются по результату. |
| `ASLa` | Арифметический сдвиг влево (аккумулятор) | 🚫 | Как `ASL`, но работает с `[A]` вместо адреса памяти. |
| `DEC` | Уменьшение значения в памяти | 🐏 | Вычитает единицу из значения по адресу `address`, также обновляя флаги `Z` и `N`. |
| `DEX` | Уменьшение регистра X | 🚫 | Вычитает единицу из `[X]`, также обновляя флаги `Z` и `N`. |
| `DEY` | Уменьшение регистра Y | 🚫 | Вычитает единицу из `[Y]`, также обновляя флаги `Z` и `N`. |
| `INC` | Увеличение значения в памяти | 🐏 | Прибавляет единицу к значению по адресу `address`, также обновляя флаги `Z` и `N`. |
| `INX` | Увеличение регистра X | 🚫 | Прибавляет единицу к `[X]`, также обновляя флаги `Z` и `N`. |
| `INY` | Увеличение регистра Y | 🚫 | Прибавляет единицу к `[Y]`, также обновляя флаги `Z` и `N`. |
| `LSR` | Логический сдвиг вправо | 🐏 | Сдвигает все биты значения по адресу `address` на одну позицию вправо. Бит `0` помещается во флаг `C`, а бит `7` устанавливается в `0`.<br><br><div class="embed-image"><img alt="LSR" src="assets/bitshifts/LSR.gif" width="186" height="115"/></div><br>Флаги `Z` и `N` обновляются по результату. |
| `LSRa` | Логический сдвиг вправо (аккумулятор) | 🚫 | Как `LSR`, но работает с `[A]` вместо адреса памяти. |
| `ROL` | Циклический сдвиг влево | 🐏 | Сдвигает все биты значения по адресу `address` на одну позицию влево. Бит `7` помещается во флаг `C`, а бит `0` заполняется прежним значением флага `C`.<br><br><div class="embed-image"><img alt="ROL" src="assets/bitshifts/ROL.gif" width="186" height="115" /></div><br>Флаги `Z` и `N` обновляются по результату. |
| `ROLa` | Циклический сдвиг влево (аккумулятор) | 🚫 | Как `ROL`, но работает с `[A]` вместо адреса памяти. |
| `ROR` | Циклический сдвиг вправо | 🐏 | Сдвигает все биты значения по адресу `address` на одну позицию вправо. Бит `0` помещается во флаг `C`, а бит `7` заполняется прежним значением флага `C`.<br><br><div class="embed-image"><img alt="ROR" src="assets/bitshifts/ROR.gif" width="186" height="115" /></div><br>Флаги `Z` и `N` обновляются по результату. |
| `RORa` | Циклический сдвиг вправо (аккумулятор) | 🚫 | Как `ROR`, но работает с `[A]` вместо адреса памяти. |
| `SBC` | Вычитание с переносом | 🔢 | Вычитает `value` из `[A]` вместе с инверсией флага переноса.<br><br>Обновляются флаги `Z`, `N`, `C` (устанавливается, если заём не потребовался) и `V` (устанавливается при неверном знаке).<br><br>Можно реализовать вызовом `ADC` с отрицательным представлением `value` минус 1.<br>Пример:<br>`SBC(cpu, value) { ADC(cpu, 256 - value - 1) }` |

#### 📈 Данные

| Код | Название | Арг. | Описание |
| --- | -------- | ---- | -------- |
| `CLC` | Сброс флага переноса | 🚫 | Устанавливает `C` = `0`. |
| `CLD` | Сброс десятичного режима | 🚫 | Устанавливает `D` = `0`. |
| `CLI` | Сброс запрета прерываний | 🚫 | Устанавливает `I` = `0`. |
| `CLV` | Сброс флага переполнения | 🚫 | Устанавливает `V` = `0`. |
| `LDA` | Загрузка аккумулятора | 🔢 | Загружает `value` в `[A]`, также обновляя флаги `Z` и `N`. |
| `LDX` | Загрузка регистра X | 🔢 | Загружает `value` в `[X]`, также обновляя флаги `Z` и `N`. |
| `LDY` | Загрузка регистра Y | 🔢 | Загружает `value` в `[Y]`, также обновляя флаги `Z` и `N`. |
| `PHA` | Помещение аккумулятора в стек | 🚫 | Помещает `[A]` в стек. |
| `PHP` | Помещение состояния процессора в стек | 🚫 | Помещает флаги в стек (как байт с установленным битом `4`). |
| `PLA` | Извлечение аккумулятора из стека | 🚫 | Извлекает байт из стека в `[A]`, также обновляя флаги `Z` и `N`. |
| `PLP` | Извлечение состояния процессора из стека | 🚫 | Извлекает байт из стека в регистр флагов. |
| `SEC` | Установка флага переноса | 🚫 | Устанавливает `C` = `1`. |
| `SED` | Установка десятичного флага | 🚫 | Устанавливает `D` = `1`. |
| `SEI` | Установка запрета прерываний | 🚫 | Устанавливает `I` = `1`. |
| `STA` | Сохранение аккумулятора | 🐏 | Записывает содержимое `[A]` по адресу `address`. |
| `STX` | Сохранение регистра X | 🐏 | Записывает содержимое `[X]` по адресу `address`. |
| `STY` | Сохранение регистра Y | 🐏 | Записывает содержимое `[Y]` по адресу `address`. |
| `TAX` | Перенос аккумулятора в X | 🚫 | Копирует `[A]` в `[X]`, также обновляя флаги `Z` и `N`. |
| `TAY` | Перенос аккумулятора в Y | 🚫 | Копирует `[A]` в `[Y]`, также обновляя флаги `Z` и `N`. |
| `TSX` | Перенос указателя стека в X | 🚫 | Копирует `[SP]` в `[X]`, также обновляя флаги `Z` и `N`. |
| `TXA` | Перенос X в аккумулятор | 🚫 | Копирует `[X]` в `[A]`, также обновляя флаги `Z` и `N`. |
| `TXS` | Перенос X в указатель стека | 🚫 | Копирует `[X]` в `[SP]`, **НЕ** обновляя флаги. |
| `TYA` | Перенос Y в аккумулятор | 🚫 | Копирует `[Y]` в `[A]`, также обновляя флаги `Z` и `N`. |

#### ✅ Проверки

| Код | Название | Арг. | Описание |
| --- | -------- | ---- | -------- |
| `BIT` | Проверка битов | 🔢 | Проверяет, установлены ли один или несколько битов в `value`.<br><br>Флаг `Z` устанавливается, если побитовое И между значением и регистром `[A]` даёт `0` (`Z` = (`value` & `[A]`) == `0`).<br><br>Биты `7` и `6` значения копируются во флаги `N` и `V` соответственно. |
| `CMP` | Сравнение | 🔢 | Сравнивает `[A]` с `value`, обновляя `Z`, `N` и `C` так:<br><br>`Z` = `[A]` == `value`<br>`N` = (установлен ли бит `7` у (`[A]` - `value`))<br>`C` = `[A]` >= `value` |
| `CPX` | Сравнение регистра X | 🔢 | Сравнивает `[X]` с `value`, обновляя `Z`, `N` и `C` так:<br><br>`Z` = `[X]` == `value`<br>`N` = (установлен ли бит `7` у (`[X]` - `value`))<br>`C` = `[X]` >= `value` |
| `CPY` | Сравнение регистра Y | 🔢 | Сравнивает `[Y]` с `value`, обновляя `Z`, `N` и `C` так:<br><br>`Z` = `[Y]` == `value`<br>`N` = (установлен ли бит `7` у (`[Y]` - `value`))<br>`C` = `[Y]` >= `value` |
| `AND` | Логическое И | 🔢 | Выполняет побитовое логическое И между `[A]` и `value` (`[A]` & `value`), сохраняя результат в `[A]` и обновляя флаги `Z` и `N`. |
| `EOR` | Исключающее ИЛИ | 🔢 | Выполняет побитовое исключающее ИЛИ между `[A]` и `value` (`[A]` ^ `value`), сохраняя результат в `[A]` и обновляя флаги `Z` и `N`. |
| `ORA` | Логическое ИЛИ | 🔢 | Выполняет побитовое логическое ИЛИ между `[A]` и `value` (`[A]` \| `value`), сохраняя результат в `[A]` и обновляя флаги `Z` и `N`. |

#### 🔀 Ветвления

| Код | Название | Арг. | Описание |
| --- | -------- | ---- | -------- |
| `BCC` | Переход при сброшенном переносе | 🐏 | Если флаг `C` сброшен, переходит по адресу `address` **(\*)**. |
| `BCS` | Переход при установленном переносе | 🐏 | Если флаг `C` установлен, переходит по адресу `address` **(\*)**. |
| `BEQ` | Переход при равенстве | 🐏 | Если флаг `Z` установлен, переходит по адресу `address` **(\*)**. |
| `BMI` | Переход при отрицательном результате | 🐏 | Если флаг `N` установлен, переходит по адресу `address` **(\*)**. |
| `BNE` | Переход при неравенстве | 🐏 | Если флаг `Z` сброшен, переходит по адресу `address` **(\*)**. |
| `BPL` | Переход при положительном результате | 🐏 | Если флаг `N` сброшен, переходит по адресу `address` **(\*)**. |
| `BVC` | Переход при сброшенном переполнении | 🐏 | Если флаг `V` сброшен, переходит по адресу `address` **(\*)**. |
| `BVS` | Переход при установленном переполнении | 🐏 | Если флаг `V` установлен, переходит по адресу `address` **(\*)**. |
| `JMP` | Переход | 🐏 | Переходит по адресу `address`. |
| `JSR` | Переход к подпрограмме | 🐏 | Помещает текущий `[PC]` (минус один) в стек и переходит по адресу `address`. |
| `RTI` | Возврат из прерывания | 🚫 | Извлекает байт из стека в регистр флагов, затем извлекает 16-битное значение и записывает его в `[PC]`. |
| `RTS` | Возврат из подпрограммы | 🚫 | Извлекает 16-битное значение из стека и записывает его (плюс один) в `[PC]`. |

<br />

**(\*)** Все инструкции **условного** ветвления должны увеличивать `cpu.extraCycles`, если переход выполняется, или устанавливать его в `0`, если нет. Это не относится к инструкциям, которые всегда выполняют переход (например, `JMP`, `JSR`, `RTI` или `RTS`).

#### 🧙‍♂️ Системные инструкции

| Код | Название | Арг. | Описание |
| --- | -------- | ---- | -------- |
| `BRK` | Вызов прерывания | 🚫 | Увеличивает `[PC]` и вызывает программное прерывание.<br><br>`[PC]` и флаги (с установленным битом `4`) помещаются в стек, затем в `[PC]` загружается вектор прерывания `BRK` по адресу `$FFFE/F`. |
| `NOP` | Пустая операция | 🚫 | Ничего не меняет. |
